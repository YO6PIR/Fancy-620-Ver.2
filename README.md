We have developed a new version of the software, with the help of AI, which is superior and combines a very beautiful analog instrument drawn on the screen with the already known functionalities.
Features of this new controller:
Processor: STM32F103CBT6, 128KB Flash, 20KB RAM; The schematic remains the same.
Analog instrument with indications: S-meter, SWR and Modulation
VFO-DDS: Si5351, VFO, BFO, RIT, large graduated scale, small graduated scale for RIT
Display: ILI9341 SPI
LCD Library: Adafruit-GFX -HWSPI
MEMORY: EEProm I2C 24C02 - 2kB RAM, sau mai mare
